# TaskManagement
# 🚀 TaskFlow – Team Task Manager

## 📌 Overview

TaskFlow is a **Team Task Management Web Application** that helps teams organize work efficiently.
It allows users to create projects, assign tasks, and track progress with **role-based access control (Admin & Member)**.

## ✨ Key Features

### 🔐 Authentication

* User Signup & Login
* Role selection (Admin / Member)

### 👥 Role-Based Access

* Admin: Manage projects, tasks, and team
* Member: View and update assigned tasks only

### 📁 Project Management

* Create, edit, delete projects
* Add team members to projects

### ✅ Task Management

* Create and assign tasks
* Status tracking (Todo, In Progress, Done)
* Priority levels (Low, Medium, High)
* Due date support

### 📊 Dashboard

* Task statistics overview
* Completion rate visualization
* Recent tasks list

### ⏳ Smart Features

* Automatic overdue task detection
* Real-time UI updates

## ⚙️ Installation & Setup

Clone the repository:

```bash id="z92kq1"
git clone https://github.com/Vishu5140/TaskManagement.git
```

Go to project folder:

```bash id="k2m9x8"
cd TaskManagement
```

Install dependencies:

```bash id="t8p4d1"
npm install
```

Run locally:

```bash id="c7w1a9"
npm run dev
```
